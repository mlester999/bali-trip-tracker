# Our Bali Adventure 2026

A lightweight, mobile-friendly Bali itinerary for November 27 to December 1, 2026.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` for the interactive trip planner and `/itinerary` for the professional print and PDF itinerary.

## Features

- Daily itinerary with Morning, Afternoon, Evening, and overnight details where supplied.
- Activity progress saved in this browser using localStorage.
- Google Maps search links for attractions.
- Optional traveler, flight, and accommodation details stored locally and shown only when entered.
- A4 print layout and a client-side PDF download.

No backend, database, login, or external API is required.
